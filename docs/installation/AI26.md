# AI26 localhost operations

Install with:

```bash
bash scripts/install_common.sh
bash scripts/install_ai26.sh
```

Private AI26 source lists, research settings and codebooks belong in `<private-config-root>/ai26/`. The public examples remain synthetic.

The working flow is:

```text
Firefox/manual pages -> loopback capture backend -> local canonical files
RSS/other collectors ---------------------------> distributed sink
local sync/media workers -> MongoDB + Redis + CSC Allas
```

Use `data/config/ai26-localhost.env` for machine runtime variables, but use `allas-conf` for Allas credentials. Keep the browser backend on `127.0.0.1`.

Manual checks:

```bash
bash scripts/run_ai26_localhost_sync.sh
bash scripts/run_ai26_localhost_collect.sh
bash scripts/run_ai26_localhost_media.sh
bash scripts/validate_installation.sh ai26
```

After successful manual runs, install the marker-managed cron block with `bash scripts/install_cron_ai26.sh`.

Logs:
`data/logs/ai26-sync.log`, `ai26-collect.log`, `ai26-media.log`.

For browser setup details also see `docs/AI26_FIREFOX_BROWSER_COLLECTION.md`.
