# Canonical Collection Record

Collection implements the source/core portion of the project-wide LaclauGPT canonical data contract. The normative cross-module specification lives in `TomiToivio/LaclauGPT/docs/CANONICAL_DATA_CONTRACT.md`.

## Identity

`source_url` is the semantic identity anchor. Ordinary web URLs are canonicalized deterministically by lowercasing scheme/host, removing fragments, removing common tracking parameters, and normalizing safe trailing slashes. Sources without a normal web URL use stable URI-like identifiers such as `at://...`, `telegram:...`, or `file+sha256:...`.

Platform IDs remain under `source_native_ids`. Mongo `_id`, SQLite PKs and row numbers never replace source identity.

## Canonical shape

Collection emits:

```text
CanonicalRecord
├── schema_version
├── source_url
├── source_native_ids
├── source
├── content
├── evidence
├── analysis
├── provenance
├── review
└── legacy
```

Collection normally populates `source`, source-side `content`, media/file references and collection provenance. Empty `analysis` and `review` sections are carried forward for downstream enrichment. Text-only records are first-class records.

`NormalizedRecord` remains only as a compatibility constructor for existing collectors. It converts the previous flat constructor vocabulary into the canonical nested record immediately. Its serialized representation is canonical.

## Storage representations

JSON/JSONL is the reference nested wire form. CSV flattens only the top-level record and encodes nested sections as deterministic JSON strings. SQLite stores one canonical JSON payload per unique `source_url`. MongoDB stores the nested document directly and uses a unique `source_url` index. Backend identifiers are ignored during reconstruction.

Schema version `1.0` from the previous Collection envelope migrates explicitly to canonical `1.0.0`. Unknown persisted versions are rejected rather than silently reinterpreted.

## Legacy and repository archaeology

| Source | Classification | Decision |

| private operational repositories | PRIVATE_DO_NOT_COPY | architecture may be inspected when authorized; data/config/paths never copied |

## Null and time policy

Missing optional lists are empty lists. Missing optional scalars are `None` where absence is meaningful. Persisted times should be ISO 8601 and timezone-aware when generated by Collection. Original source timestamp strings may be retained in source metadata when exact source semantics require it.

## Privacy

Real records, source lists, browser state, cookies, media, database files, exports and operational configuration remain under ignored `data/` or external private infrastructure. Public tests use synthetic records only.
